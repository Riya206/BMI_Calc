**BMI Calculator – React App**

A simple and interactive Body Mass Index (BMI) Calculator built using React.
The application calculates BMI based on height, weight, and gender, then displays the health category along with a representative image.

**Features**

Calculate BMI instantly
Supports kg / lb weight units
Supports cm / inch height units
Gender-based result display
Health category detection
Result image visualization
Recalculate option
Beginner-friendly React Hooks project

**Tech Stack**
React (Functional Components)
useState Hook
JavaScript (ES6)
HTML + CSS
Image Assets
